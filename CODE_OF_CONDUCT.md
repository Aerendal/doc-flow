# Kodeks postępowania / Code of Conduct

## Nasze zobowiązanie

W ramach tego projektu zobowiązujemy się tworzyć środowisko otwarte i szanujące wszystkich uczestników, niezależnie od poziomu doświadczenia, języka, płci, orientacji, niepełnosprawności, wyglądu, narodowości czy przekonań.

## Oczekiwane zachowania

- Używaj języka przyjaznego i inkluzywnego.
- Szanuj różne punkty widzenia i doświadczenia.
- Przyjmuj konstruktywną krytykę.
- Skup się na tym, co jest najlepsze dla projektu i społeczności.
- Okazuj empatię innym członkom społeczności.

## Niedopuszczalne zachowania

- Użycie języka lub obrazów o charakterze seksualnym.
- Trolling, obraźliwe/deprecjonujące komentarze, ataki personalne lub polityczne.
- Nękanie publiczne lub prywatne.
- Publikowanie prywatnych informacji innych osób bez ich wyraźnej zgody.
- Inne zachowania, które można rozsądnie uznać za nieodpowiednie w środowisku zawodowym.

## Zakres

Kodeks dotyczy przestrzeni projektu: Issues, Discussions, Pull Requests, komentarzy w repo, a także reprezentowania projektu w przestrzeniach publicznych.

## Egzekwowanie

Naruszenia można zgłaszać do maintainerów przez GitHub Security Advisory (prywatnie) lub bezpośrednio do właściciela repo. Wszystkie zgłoszenia będą rozpatrzone poufnie. Maintainerzy mają prawo do usuwania, edytowania lub odrzucania komentarzy, commitów, issues i innych wkładów niezgodnych z tym kodeksem, a także do tymczasowego lub trwałego zbanowania uczestnika.

## Atrybucja

Oparty na [Contributor Covenant](https://www.contributor-covenant.org), wersja 2.1.
