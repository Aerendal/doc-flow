# Support / Gdzie pytać o pomoc

Proszę stosować następujące kanały (priorytety):

1. Discussions — pytania, prośby o pomoc, dyskusje koncepcyjne.
   - Link: https://github.com/Aerendal/doc-flow/discussions
2. Issues — tylko reproducible bugs (użyj formularza "Bug report").
3. Security — luki bezpieczeństwa raportuj tylko przez procedurę w [SECURITY.md](/SECURITY.md). NIE publikuj podatności publicznie

Język: preferuję polski. Dla logów i reprodukcji proszę o angielski, jeśli to możliwe.

Jeśli nie jesteś pewien, gdzie zgłosić — stwórz Discussion i przeniosę/zasugeruję odpowiedni kanał.
